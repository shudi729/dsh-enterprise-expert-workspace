# 企业 AI 专家工作台 1.6.0

这是面向公开发行与 dsh.so 市场审核准备的首个版本。

## 亮点

- 10 个企业业务方向、61 个 Skill、13 条跨领域工作流。
- 任务式工作台：资料、流程、状态、结论、成果和知识在同一条链路中管理。
- 支持 Word、Excel、PowerPoint、PDF、Markdown、CSV、JSON 与 TXT 的读取或生成。
- 采购、候选人和数据比较具备口径检查；资料不足或模型结论冲突时不会给出虚假完成状态。
- 支持任务续做、草稿恢复、成果版本、知识审核和隔离工作空间。
- 公开发行包已移除私人知识原件、迁移摘录、凭据、日志与测试数据。

## 安全与分发改进

- 用内置 Open XML 读写替代存在已知漏洞的旧版表格和演示依赖。
- YAML 解析依赖升级到修复版本。
- 增加权限边界、隐私披露、发布包哈希核对和隔离 profile 安装要求。
- 生产依赖本地审计无已知漏洞；最终结果仍以 npm 与 dsh.so 对公开 tarball 的扫描为准。

## 已验证环境

- DSH `0.2.1-rc.5`
- Node.js `24.22.1`
- Windows
- Chrome 157，桌面和 430px 窄屏

## 已知边界

- 扫描版 PDF 暂无 OCR。
- 未提供真实企业系统凭据，连接器需由用户单独配置和验证。
- 未完成其他浏览器与移动真机覆盖，不将自动化验收表述为真人可用性测试。
