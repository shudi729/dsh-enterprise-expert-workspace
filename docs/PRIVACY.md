# 隐私与数据说明

## 本地数据

任务、草稿、成果、知识和用户技能默认保存在当前 DSH profile 的 `enterprise-expert-workspace` 数据目录。插件升级和卸载不会主动删除这些数据。

## 外部传输

插件自身不包含广告、分析或遥测服务。只有当当前 DSH profile 已配置模型提供方，并且用户执行需要模型分析的任务时，相关提示和任务资料才会通过 DSH 的 `llm` 服务发送给该提供方。具体保留与处理规则由所选模型服务决定。

公开版不预置业务系统账号。连接器配置和外部动作默认拒绝，必须经过显式授权。

## 凭据

插件不打包、不展示、不复制 API Key。凭据由 DSH profile 管理。请勿把密钥写入知识库、任务资料、Issue 或日志。

## 使用者责任

使用者应确认对导入资料拥有合法处理权限，并根据组织政策设置访问控制、备份、保留期限、磁盘加密和模型数据边界。
